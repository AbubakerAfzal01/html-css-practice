# Day 06 — HTML Forms

## Overview

Day 06 focuses on collecting user input using HTML forms — creating form structures, submitting data using GET and POST methods, connecting labels with form controls, and working with different types of input fields.

## Topics Covered

* `<form>` tag
* `action` attribute
* `method` attribute
* GET and POST methods
* `<input>` element
* `type="text"`
* `type="email"`
* `type="password"`
* `type="number"`
* `type="date"`
* `<label>` tag
* `for` and `id`
* `name` attribute
* `placeholder` attribute
* `required` attribute
* `<button type="submit">`
* Basic client-side form validation

## Practical Work

Built multiple forms to practice different concepts:

* A basic GET search form
* A product search form using GET
* A basic POST login form
* A login form using account number and PIN
* A label and input example using `for` and `id`
* A label-wrapped input example
* A user profile form using name, email, password, age, and date of birth fields
* Practiced different input types and basic form validation

## Learning Outcome

By the end of Day 06, I can create basic HTML forms for collecting different types of user input. I understand how `<form>`, `action`, and `method` work together to submit form data.

I can use GET and POST appropriately, create different `<input>` types, connect `<label>` elements using `for` and `id`, and understand the purpose of the `name` and `placeholder` attributes.

I also understand basic client-side validation using attributes such as `required`, and I know that server-side validation is still necessary for real applications.
