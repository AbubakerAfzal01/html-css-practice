
# Day 07 — Semantic HTML & Accessibility

## Overview
Day 07 focuses on writing meaningful HTML structure using semantic elements instead of generic divs, understanding heading hierarchy, and learning the basics of web accessibility.

## Topics Covered
- `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`
- Difference between `<section>` and `<article>`
- Div-soup and when `<div>` is still appropriate
- Heading hierarchy (one `<h1>` per page, logical order)
- `<main>` used once per page
- Basic accessibility concepts
- Keyboard accessibility (Tab, Shift+Tab, Enter)
- `aria-label`

## Practical Work
Built a simple, honest student portfolio page using proper semantic structure:
- `<header>` with name and short intro
- `<nav>` with fragment links to each section
- `<main>` containing `<section>`s for profile and education, with `<article>` for individual education entries
- `<aside>` for contact details
- `<footer>` with copyright

## Learning Outcome
By the end of Day 07, I can structure a webpage using semantic HTML elements instead of relying on generic `<div>` containers, understand when to use `<section>` vs `<article>`, and follow a logical heading hierarchy.
I also understand the basics of accessibility, including keyboard navigation and when `aria-label` is useful. I learned that writing correct-looking HTML is not the same as understanding it — I need to be able to explain my own code.
