# Day 01 — HTML Fundamentals

## Overview

Day 01 focuses on the fundamentals of HTML and the basic structure of a web page.

The goal was to understand how HTML documents are structured and how HTML elements, tags, attributes, headings, paragraphs, and comments are used to organize content.

## Topics Covered

- What is HTML?
- What is HTML5?
- `<!DOCTYPE html>`
- HTML document structure
- `<html>`
- `<head>`
- `<meta>`
- `<title>`
- `<body>`
- HTML tags and elements
- HTML attributes
- Heading elements `<h1>` to `<h6>`
- Paragraph element `<p>`
- HTML comments
- Proper indentation
- Proper nesting

## Practical Work

Built a personal introduction webpage using HTML only.

The page includes:

- Main heading
- Section headings
- Paragraphs
- HTML comments
- Basic document metadata
- Proper HTML structure
- Proper indentation and nesting
