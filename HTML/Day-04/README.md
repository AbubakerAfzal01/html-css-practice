# Day 04 — Images & Media

## Overview

Day 04 focuses on adding and working with images and different types of media in HTML. The goal was to learn how to display images, control their dimensions, add captions, embed audio and video, add video captions, embed external content using iframes, and improve loading performance using lazy loading.

## Topics Covered

* `<img>` tag
* `src` and `alt` attributes
* `width` and `height` attributes
* Image aspect ratio
* `<figure>` and `<figcaption>`
* `<audio>` tag
* `controls` attribute
* `<source>` element
* `<video>` tag
* `poster` attribute
* `autoplay` and `muted`
* `<track>` for subtitles and captions
* `<iframe>` tag
* `title` attribute in `<iframe>`
* iframe security restrictions
* `loading="lazy"`
* `src` vs `href`

## Practical Work

Built a single HTML page demonstrating different types of images and media elements.

The page includes:

* A basic image using `<img>` with `src`, `alt`, `width`, and `height`
* An image grouped with `<figure>` and `<figcaption>`
* A code example inside `<figure>`
* An audio player using `<audio>`, `<source>`, and `controls`
* A video player using `<video>`, `<source>`, and `controls`
* A video with subtitles using `<track>` and a `.vtt` file
* Embedded external content using `<iframe>`
* A lazy-loaded image using `loading="lazy"`

## Learning Outcome

By the end of Day 04, I can add images to HTML pages, provide meaningful alternative text, control image dimensions, and organize visual content using `<figure>` and `<figcaption>`.

I can also embed audio and video, add subtitles using `<track>`, use video posters and autoplay with muted, embed permitted external content using `<iframe>`, apply lazy loading, and understand the basic difference between `src` and `href`.
