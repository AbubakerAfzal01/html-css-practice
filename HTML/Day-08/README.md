
# Day 08 — HTML Mini Project + Revision

## Overview
Day 08 combines everything learned from Day 01 to Day 07 into a single 4-page website — Home, About, Projects, and Contact — connected through shared navigation. This marks the end of the HTML phase.

## Pages Built
- **index.html (Home)** — intro section, profile photo with `<figure>`/`<figcaption>`, quick links to other pages
- **about.html** — personal story in an `<article>`, a skills description list (`<dl>`), a fun-fact `<aside>`, and a timeline (`<ol>`)
- **projects.html** — a projects table using `<caption>`, `<thead>`, `<tbody>`, `<tfoot>`, `scope`, and `colspan`
- **contact.html** — a contact form with labeled inputs (text, email, number, date) and required fields, plus an `<address>` with mailto/tel links

## Concepts Combined (Days 01–07)
- Text formatting and semantic inline tags
- Lists (unordered, ordered, description)
- Links and navigation (relative paths, fragment links, mailto, tel)
- Images, figure/figcaption
- Tables with accessible headers
- Forms with labeled, validated inputs
- Semantic page layout (header, nav, main, section, article, aside, footer)

## Files
- `index.html`, `about.html`, `projects.html`, `contact.html`
- `notes.txt` — Detailed Day 08 notes, including a full revision summary of Days 01–07
- `README.md` — Day 08 summary

## Learning Outcome
By the end of Day 08, I can build a multi-page website from scratch using only semantic HTML, connect pages with consistent navigation, and combine text, lists, links, media, tables, and forms into one coherent structure — without following a step-by-step tutorial.

This completes the HTML phase of the course. The next phase is CSS, starting at Day 09.
