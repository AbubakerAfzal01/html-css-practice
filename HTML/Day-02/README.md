# Day 02 — Text Formatting & Lists

## Overview

Day 02 focuses on text-level semantic formatting and HTML lists — how to give meaning to inline text and organize content into structured, hierarchical lists.

The goal was to understand semantic text tags (importance vs emphasis, quotations, abbreviations) and to build both unordered and ordered lists, including nested lists and description lists.

## Topics Covered

- `<strong>` — important text
- `<em>` — emphasized text
- Unordered lists `<ul>`
- Ordered lists `<ol>`
- List items `<li>`
- Nested lists
- Description lists `<dl>`, `<dt>`, `<dd>`
- `<del>` and `<ins>`
- `<sub>` and `<sup>`
- `<blockquote>` and the `cite` attribute
- `<q>` (inline quotation)
- `<abbr>` and the `title` attribute
- `<code>`

## Practical Work

Built a personal learning-profile webpage using HTML only.

The page includes:

- A paragraph using `<strong>` and `<em>` for semantic emphasis
- An unordered list of technologies being learned
- An ordered list describing the learning process
- A nested list showing a tech stack broken into categories
- A description list defining key web development terms
- Examples of `<del>`/`<ins>`, `<sub>`/`<sup>`, `<blockquote>`, `<q>`, `<abbr>`, and `<code>`

## Learning Outcome

By the end of Day 02, I can format text with correct semantic meaning instead of just visual styling, and I can build both flat and nested lists along with description lists.

I can also use quotation, abbreviation, and inline-code tags with proper attributes, and I understand the difference between purely visual tags (`<b>`, `<i>`) and semantic tags (`<strong>`, `<em>`).
