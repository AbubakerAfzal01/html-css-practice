# Day 05 — HTML Tables

## Overview
Day 05 focuses on organizing data using HTML tables — creating rows, columns, headers, and structured sections, and using attributes that merge cells or improve accessibility.

## Topics Covered
- `<table>`, `<tr>`, `<th>`, `<td>`
- `<caption>`
- `<thead>`, `<tbody>`, `<tfoot>`
- `colspan`
- `rowspan`
- `scope="col"` and `scope="row"`

## Practical Work
Built multiple tables to practice different concepts:
- A basic employee information table with a `<caption>`
- A `<thead>`/`<tbody>`/`<tfoot>` version of the same table, including a `colspan` summary row
- A Fruits/Vegetables table demonstrating `rowspan`
- A final Semester Exam Report table combining `<caption>`, `<thead>` with `scope="col"`, a meaningful `rowspan` for a student with two subjects, and a `<tfoot>` summary using `colspan`

- `index.html` — Day 05 table practice

## Learning Outcome
By the end of Day 05, I can build structured HTML tables using `<table>`, `<tr>`, `<th>`, and `<td>`, give a table a title with `<caption>`, and organize it into `<thead>`, `<tbody>`, and `<tfoot>` sections.
I can also merge cells using `colspan` and `rowspan`, and use `scope` to make table headers more accessible.
