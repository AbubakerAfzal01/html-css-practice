# Day 03 — Links, Paths & Navigation

## Overview
Day 03 focuses on connecting HTML pages together using hyperlinks, and understanding how paths (relative and absolute) work. The goal was to learn how to link internal pages, external websites, specific sections of a page, and contact methods like email and phone, then organize all of this into a proper semantic navigation menu.

## Topics Covered
- `<a>` tag and `href` attribute
- Relative paths
- Absolute paths
- Internal links vs external links
- Fragment links (`#id`)
- Email links (`mailto:`)
- Telephone links (`tel:`)
- `target="_blank"`
- `rel="noopener noreferrer"`
- `<nav>` (semantic navigation)
- Navigation lists using `<ul>` and `<li>`

## Practical Work
Built a 3-page website (Home, About, Contact) connected through a shared navigation menu.
The pages include:
- A navigation menu (`<nav>`, `<ul>`, `<li>`) present on all three pages
- Relative links connecting Home, About, and Contact
- An absolute link to an external website with `target="_blank"` and `rel="noopener noreferrer"`
- A fragment link on the Home page jumping to a Contact heading
- An email link and a phone link on the Contact page

## Files
- `index.html` — Day 03 Home page
- `about.html` — Day 03 About page
- `contact.html` — Day 03 Contact page
- `notes.txt` — Detailed Day 03 notes
- `README.md` — Day 03 summary

## Learning Outcome
By the end of Day 03, I can connect multiple HTML pages using relative links, create external links using absolute URLs, and navigate to specific sections using fragment links.
I can also create email and phone links and build a proper semantic navigation menu using `<nav>`, `<ul>`, `<li>`, and `<a>`.
