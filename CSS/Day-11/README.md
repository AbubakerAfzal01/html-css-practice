# Day 11 — Box Model & Units

## Overview
Day 11 covers the CSS Box Model — how content, padding, border, and margin work together — along with box-sizing and the main CSS units (px, %, rem, em, vw, vh).

## Topics Covered
- The Box Model (content, padding, border, margin)
- `box-sizing`: `content-box` vs `border-box`
- The universal `* { box-sizing: border-box; }` rule
- CSS units: `px`, `%`, `rem`, `em`, `vw`, `vh`
- `list-style-type` for customizing or removing bullets

## Practical Work
Applied box model properties and CSS units to an existing HTML page — added padding/margin/border to the header, nav, and sections, set a fixed-width box with border-box sizing, removed default nav bullets, and experimented with `rem`, `%`, and `vw` for sizing.

## Learning Outcome
By the end of Day 11, I understand how the box model determines an element's actual size, why `border-box` is the professional default, and when to use each CSS unit. I also learned firsthand how `100vw` can cause horizontal scrolling and why `%` is often the safer choice.
