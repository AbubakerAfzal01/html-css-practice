# Day 09 — CSS Basics & Selectors

## Overview
Day 09 introduces CSS — how it connects to HTML, basic selectors, specificity, colors, and typography. This is the first day of the CSS phase, using external CSS as the standard approach going forward.

## Topics Covered
- What CSS is and how it differs from HTML
- Three ways to connect CSS (inline, internal, external)
- Element, class, and ID selectors
- Basic CSS specificity (Element < Class < ID)
- Colors: named colors, HEX, RGB, RGBA
- Typography: `font-family`, `font-size`, `font-weight`, `text-align`
- Fallback fonts

## Practical Work
Set up an external stylesheet (`style.css`) linked to `index.html`. Styled a heading and paragraphs using element, class, and ID selectors, explored specificity conflicts, tried RGB/RGBA colors, and applied basic typography to the page.

## Files
- `index.html` — Day 09 HTML structure
- `style.css` — Day 09 external stylesheet
- `notes.txt` — Detailed Day 09 notes
- `README.md` — Day 09 summary

## Learning Outcome
By the end of Day 09, I can connect an external CSS file to HTML, style elements using element, class, and ID selectors, and understand how specificity decides which rule wins when selectors conflict. I can also apply basic color and typography styling.
